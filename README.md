# How is this different than a strategy game or LLM?
All LLMs have the same issue. Whether it be D&D, a civilization simulation, or anything else. That is simply, memory. The AI **will** forget things. Every strategy game allows you to do *what the developer planned for*, which closes out creativity. Due to my frustration with this, I made this project.

# How does it work?
With a locally hosted LLM, (~10GB reccomended space) this game will give you the best of both worlds without the tradeoffs of either. By having Python enforce backend rules, and the AI parsing player actions and narrating the events that follow from it, you have a dynamic game every single time. That is exactly what this project aims to do, while not closing the door to player creativity and ideas.
